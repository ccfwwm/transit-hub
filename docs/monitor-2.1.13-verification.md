# 2.1.13 分组检测与媒体任务

实现按分组 ID 配置检测模型、文本/连接/图片/视频类型及媒体参数；渠道模型覆盖所有所属分组，各分组仍单独保存健康状态和历史。升级不会自动开启媒体生成。

图片/视频采用独立双工作线程队列，提交前在 PostgreSQL 原子登记任务。任务保存原始检测参数，轮询原任务 ID；提交结果不明确、重启时无任务 ID、观察超时均阻止自动重新提交。显式重置后才允许新提交。真实生成产物须通过图片完整解码或 ffprobe 视频流和时长验证，验证文件随后删除。生产镜像安装 ffmpeg。

共享调度账号只有所有检测分组连续失败达到阈值才自动停用；未检测、生成中、配置错误不满足阈值。恢复遵守余额、手动停止、人工覆盖与接管保护。

监控页面使用轻量汇总与服务端分页，每页 25/50/100 条；分组可用状态、分组 ID、渠道状态及搜索分别筛选。历史采用当前页批量索引查询，每目标至多 60 点，完整错误按需查询。上游账号和分组使用 15 秒缓存与并发合并。
